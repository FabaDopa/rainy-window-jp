# rainy-window-jp

> **非公式の改造版です。** [Ishu Agrawal](https://github.com/ishuagrawal) さんの [rainy-window](https://github.com/ishuagrawal/claude-code-themes)（MIT）をもとに、個人が作りました。Anthropic の公式のものではありません。部屋の絵や仕組みは元の作者のもので、足したのは下の「4つ」と「クロードくん」です（くわしくは「もとにした mod と作者」）。

Claude デスクトップアプリ（Code タブ）の背景 mod です。雨の日のクロードくんの部屋（rainy-window）に、次の4つを足しました。

1. 壁の時計が **日本時間** を指す
2. 部屋の **背景色を5色** から選べる（紺・緑・桜・橙・灰）
3. **時間帯（朝・昼・夕方・夜）** で部屋の明るさや色合いも変わる
4. 色は **すべての会話・このフォルダ・この会話だけ** のどこに保存するか選べる。`/rj` と打つと、入力欄の上にボタンで選べるカードが出る

部屋の雰囲気がいちばん大きく変わるのは、**アプリの明るさ（設定 → 外観 → テーマ：🖥 システム／☀ ライト／🌙 ダーク）** です。☀ は昼の部屋、🌙 は夜の部屋になり、🖥 は Windows の明るさに合わせます。この切り替えはアプリの設定で行います（mod からは変えられません）。

何も設定していなければ「紺・夜」の部屋です。暗い画面では元の rainy-window と同じ夜の部屋（時計の針だけ本物の日本時間）、明るい画面では淡い紺（青み）の部屋になります。AI を呼ばず、ネットワークにも出ません。時刻は PC の時計を `Intl`（`Asia/Tokyo`）で日本時間に読み替えて使います。

## もとにした mod と作者

- 元の mod：**rainy-window**（作者 [Ishu Agrawal](https://github.com/ishuagrawal)、リポジトリ [ishuagrawal/claude-code-themes](https://github.com/ishuagrawal/claude-code-themes)、MIT ライセンス）
- 部屋の絵（`hooks/scene.ts`）、色を作る仕組み（`hooks/make-colors.js`）、クロードくん（元の作者の呼び名は Clawd）の体と顔（`hooks/clawd/body.ts`）と、もとの打っている動き（`hooks/clawd/sheet.ts` の `clawdSheet`）は元のものです。
- `hooks/clawd/` のほかの絵（Haiku・Opus・Fable の姿、状態ごとの動き、effort の演出、サブエージェントの子、層の組み立て）は、元の体と顔をもとに、この mod で描いたものです。
- `scene.ts` は、時計の針の角度と部屋の色を受け取るところのほかに、クロードくんの層を部屋の絵の中に入れるところ、作り直した絵の動きを前の続きから始めるところ、細かいドットのマスクを足しています。

## 元の rainy-window とは一緒に使えません

見た目（テーマ）は1つのセッションに1つだけです。元の rainy-window も有効だと、2つの mod が上書きし合います。使う前に、元のほうで次を打って止めてください（止めた状態は次のセッションでも続きます）。

```
/rainy-window off
```

## 入れ方

Claude デスクトップアプリ（Claude Code 2.1.325 以降）が必要です。入れる前に、元の rainy-window を止めてください（上の節）。

### マーケットプレイスから入れる（かんたん）

**デスクトップアプリ：** 入力欄の左の **＋** → **Plugins** → **Add marketplace** に `FabaDopa/rainy-window-jp` と入れて追加し、**rainy-window-jp** を **Add plugin** で入れます。

**ターミナル：** プロンプトで次を打ちます（途中で `y`、そのあと保存先を聞かれます）。

```
/plugin install rainy-window-jp --marketplace FabaDopa/rainy-window-jp
```

入れたあとに始めた新しいセッションから読み込まれます。外すときは `/plugin` の Installed から削除してください。

### 手元のフォルダから試す

このリポジトリを自分の PC に取ってきて、次のどちらかで読み込みます。

**デスクトップアプリ（Code タブ）で使うとき：** `~/.claude/settings.json`（Windows では `C:\Users\<あなた>\.claude\settings.json`）の `env` に、このフォルダを `CLAUDE_CODE_PLUGIN_DIRS` として書きます。プロジェクトの設定ファイルではなく、この自分用の設定ファイルに書いてください。すでに `env` がある場合は、その中に1行足します。JSON の中では `\` を `\\` と2つ重ねて書きます。

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "C:\\このフォルダの場所\\rainy-window-jp"
  }
}
```

書いたあとに始めた新しいセッションから読み込まれます。

**ターミナルで使うとき：** このフォルダを指定して起動します。ただし、ターミナルには背景（部屋の絵や色）は出ません。背景が出るのは、デスクトップアプリやスマホのアプリで同じ会話を開いているときだけです。

```bash
claude --plugin-dir <このフォルダの場所>
```

試したのは Claude Code 2.1.325（デスクトップアプリに入っている版）です。

## `/rj` の使い方

### カードで選ぶ

`/rj` と打つと、入力欄のすぐ上にカードが出ます（会話が進んでも流れていきません）。もう一度 `/rj` と打つと閉じます。

```
Rainy window JP                                                [閉じる]
[🎨 背景 ✓] [🐾 クロードくんの見た目]
━━━━━━━━━━━━───────────────────────────
🎨 背景
保存してある設定：紺・夜（標準）
背景色　 [🟦 紺 ✓] [🟩 緑] [🌸 桜] [🟧 橙] [⬜ 灰]
時間帯　 [自動（いま夕方）] [朝] [昼] [夕方] [夜 ✓]
保存先　 [すべての会話 ✓] [このフォルダ] [この会話だけ]
[保存して閉じる]  [保存先の設定を消す]  [オフにする]
💡 明るい・暗いは、アプリの 設定 → 外観 → テーマ（🖥 ☀ 🌙）で切り替えます。…
```

- カードには **🎨 背景** と **🐾 クロードくんの見た目** の2つのタブがあります。開いたときは背景のタブです（見た目のタブは、下の「クロードくん」を見てください）。
- 色・時間帯・「オフにする」を押すと、**その場で背景が変わります**（まだ保存はしません）。続けてポンポン押して試せます。
- **保存して閉じる**：今見えている色と時間帯、それにクロードくんの見た目（姿・演出・ドット）を、「保存先」に選んだ場所にまとめて保存して、カードを閉じます。
- **保存先の設定を消す**：選んだ保存先の設定をやめて、1つ広い場所の設定に戻ります。
- **オフにする**：この mod の見た目を外して、アプリ本来の見た目にします（保存すると、その保存先ではオフのまま）。
- **閉じる**（または `/rj` をもう一度）：保存せずに閉じます。見た目は保存してある設定に戻ります。
- 時間帯の **自動** は、日本時間で 朝 5時・昼 10時・夕方 16時・夜 19時 に切り替わります（メッセージを送ったときに見ます）。ボタンには今の時間帯が出ます。
- カードを開いたまま会話を続けても、試している見た目はそのままです（勝手に戻りません）。

### 打って指定する

```
/rj <背景色> [時間帯] [p|s]
/rj reset [p|s]
```

- 背景色：`紺 緑 桜 橙 灰`、`オフ`（英語 `navy green pink orange gray off` でも可）
- 時間帯：`自動`、または `朝 昼 夕方 夜`（`auto morning day evening night`）
- 保存先：書かない＝すべての会話、`p`＝このフォルダ、`s`＝この会話だけ
- 語の順番は自由です。書かなかった項目は、その場所に保存されていた値（無ければ標準）を引き継ぎます。

例：

```
/rj 緑            … すべての会話を緑に
/rj 緑 自動 p     … このフォルダだけ、緑・時間帯で自動
/rj 紺 夜 s       … この会話だけ、紺・夜に固定
/rj reset p       … このフォルダの設定を消す
```

分からない言葉があると、何も変えずに使い方を返します。前の版の名前（雨・森・墨・葡萄）も、近い色（紺・緑・灰・桜）として通ります。

## 設定の効き方

- 優先順位は **この会話だけ ＞ このフォルダ ＞ すべての会話 ＞ 標準**（狭いものが勝つ）。
- 標準（何も保存していないとき）は、紺・夜。暗い画面では元の rainy-window と同じ見た目、明るい画面では淡い紺の部屋です。
- 「このフォルダ」は会話を始めたフォルダごとです。git のワークツリーは、元のフォルダと同じとして扱います。
- 別の会話で「すべての会話」や「このフォルダ」の設定を変えたときは、開いている他の会話は **次のメッセージを送ったとき** に切り替わります。
- テーマを付け直すのは、色や時間帯が変わったときだけです。クロードくんの様子が変わったときは、部屋の絵（1枚）だけを描き直します（多くても 2 秒に1回）。描き直した絵でも、雨や明かりは前の続きから動きます。

## 色について

- いちばん大きく変わるのはアプリの明るさ（設定 → 外観 → テーマ）です。同じ背景色でも、☀ ライトでは昼の明るい部屋、🌙 ダークでは夜の暗い部屋になります。
- 背景色で変わるのは、**部屋の壁・床の色と、窓や照明の光の色合い**、それにアプリの面の色です。家具と窓の外の景色（元の絵のまま）と、クロードくん（姿・動き・演出はこの mod で描いたもの。体と顔は元のもの）は、背景色では変わりません。
- 時間帯では、部屋が 朝・昼 は明るく、夕方 は暖かい色合いに、夜 はその色の基準の暗さになります。
- 文字の色とアクセントの色は、どの色でも元のままです。

## クロードくん

部屋の右下にいるクロードくん（元の作者の呼び名は Clawd）が、Claude の様子に合わせて動きます。雨と時計は止まりません（部屋とクロードくんは、1枚の絵の中で動いています）。AI を呼ばず、ネットワークにも出ません。

### 姿（使っているモデルで決まる）

| モデル | 姿 |
| --- | --- |
| Sonnet | 今までのクロードくん（ノートパソコンとマグ） |
| Haiku | 小さいクロードくん3人 |
| Opus | マエストロ（白いふさふさの髪・燕尾服・赤い蝶ネクタイ・指揮棒。ノートパソコンの代わりに譜面台） |
| Fable | 教授（角帽・まるいめがね。うしろに黒板） |

モデル名に `haiku`・`sonnet`・`opus`・`fable` のどれが入っているかで決めます。どれでもなければ Sonnet の姿です。アプリのメニューでモデルを変えると、メッセージを送らなくても 1〜2 秒で姿が変わります。

### 動き（メッセージを送ってから）

待つ（こちらを見てにこにこ。ときどき小さな動き）→ 送ると「！」→ 考え中（吹き出しに「…」）→ 道具（歯車の吹き出し）→ 返事を書く（吹き出しの行が増える）→ やった（バンザイなど）→ 手をふる → 待つ。考える・道具・書くは1回の返事の中で行き来します。ちらつかないよう、1つの状態は最低 1.5 秒見せます。

### effort の演出

アプリで選んでいる effort（思考の深さ）に合わせて、動いている間だけ演出が出ます。

| effort | 演出 |
| --- | --- |
| low | なし |
| medium | 数字の雨（緑の 0 と 1 がうしろに降る） |
| high | 炎の柱（炎の色は姿ごと） |
| xhigh | 虹色（虹色の炎と光線） |
| max | くっきり暴走（赤い縁の炎・赤い稲妻・目が赤く） |

- 出るのは「！」から「やった」までです。待っている間は落ち着いた姿に戻ります。
- `/rj` のカードを開いている間は、選んだ演出を、待っている間でも見せます（確かめるため）。閉じると「動いている間だけ」に戻ります。
- effort が分からないとき（モデルによっては無い）は low と同じ（演出なし）です。
- 演出を出したくないときは `/rj 演出 なし`。「自動」に戻すには `/rj 演出 自動` です。

### サブエージェント

サブエージェントが動きだすと、小さいクロードくんが「ポン」と出てきて、小さいノートパソコンで打ちます（机の左・頭の上・マグの上・本体のうしろの2人。**5人まで**）。終わった子は手をふって、ポンと帰ります。本体が Haiku のときは、3人のうしろの列に **2人まで** です。子には effort の演出は付きません。

ワークフローの `agent()` が作る子は、アプリの `$.agent.list()` に出てこないので、数えず、絵にも出ません。

### カードで選ぶ（見た目のタブ）

`/rj` のカードには2つのタブがあります。**背景**（上の色・時間帯）と **クロードくんの見た目** です。見た目のタブには、姿と演出の **小さな絵が並び**、その名前のボタンが絵の下の端に重なっています（絵の下のほうを押すと選べます。絵を指すと名前が太くなります）。

```
自動＝いまのモデル（Opus）
姿　　　 [絵       ] [絵     ] [絵    ] [絵   ] [絵    ]
         [自動 ✓  ] [Sonnet ] [Haiku ] [Opus ] [Fable ]    ← ボタンは絵の上
自動＝いまの effort（max）
演出　　 [絵   ] [絵  ] [絵     ] [絵   ] [絵    ] [絵  ]
         [自動 ✓] [なし] [medium ] [high ] [xhigh ] [max ]
ドット　 [ふつう ✓] [細かい]
```

- 絵の上のボタンの名前は短く（「自動」「Sonnet」「medium」など。選んでいるものに ✓）。「自動」がいま何かは、行の上の薄い1行に書きます。
- タブの光の帯は、デスクトップではすべらず、選んだタブの形で止まって見えます（動く絵を枠として描くと、ホイールが取られて、帯のスクロールが戻らなくなるため）。

- 姿：自動（いまのモデルに合わせる）／ Sonnet ／ Haiku ／ Opus ／ Fable。絵は、その姿が机で落ち着いているところ（こちらを見てにっこり。ノートパソコン・小さい3人のノートパソコン・譜面台・黒板つき）です。
- 演出：自動（effort に合わせる）／ なし ／ medium ／ high ／ xhigh ／ max。絵は、いま選んでいる姿が返事を書いているところに、その演出をのせたものです（自動の絵は、いまの effort の演出。分からないときは演出なし）。
- ドット：ふつう ／ 細かい（細かい点で描きます。初めは「ふつう」）。絵も、選んだドットで描きます。
- 絵は動かない1枚の絵です（入力欄の上の帯は、スクロールするたびに絵を出し直すので、動く絵だと出だしの動きがくり返されてしまうため）。部屋のクロードくんは、今までどおり動きます。
- ターミナルには絵が出ません（ボタンだけ。「自動（いま Opus）」のように、ボタンの名前に書きます）。

押すとその場で部屋のクロードくんが変わり（保存はしません）、「保存して閉じる」で、背景といっしょに「保存先」に保存します。「閉じる」で、保存してある設定に戻ります。

### 打って指定する

```
/rj 姿 <自動|sonnet|haiku|opus|fable>
/rj 演出 <自動|なし|medium|high|xhigh|max>
/rj ドット <ふつう|細かい>
```

背景の語と混ぜてよく、語の順番も自由です（例：`/rj 演出 max`、`/rj 姿 opus ドット 細かい p`、`/rj 緑 演出 なし`）。保存先（`p`・`s`）の書き方は背景と同じです。

### 知っておいてほしい限り

- 部屋の絵の描き直しは、多くても 2 秒に1回です。そのため「！」は、見えるのが約 2 秒です。
- effort は、メッセージを送ったあとでないと分かりません。アプリのメニューで effort を変えても、見た目が変わるのは **次のメッセージを送ったとき** です（モデルは、送らなくても変わります）。

## 知っておいてほしいこと

- Windows の「透明効果」がオフだと、色は付くのに部屋の絵が出ません（設定 → 個人用設定 → 色 → 透明効果 をオンに）。
- 時計の針は、絵を作った時刻の日本時間から、本物の速さで進みます。絵を作り直すのは、クロードくんの様子が変わったとき（多くても 2 秒に1回）と、アプリが絵を出し直すとき（セッションを切り替えて戻ったときなど）に手元の絵が1分より古いときです。作り直した絵の針は今の時刻から始まり、雨や明かりは前の続きから動きます。そのため、針のずれは多くても1分ほどです。
- 打って指定するときだけ、明るさ（`黒`／`白`）も書けます。ただし、デスクトップアプリはまだこの指定を使わないため、効かない見込みです。

## テスト

純粋な関数（日本時間・時間帯・針の角度・設定の優先順位・色・コマンドの読み取り・キー）は Node で：

```bash
node --experimental-strip-types --import ./test/setup.mjs --test "test/*.unit.ts"
```

mod としての動き（コマンド・保存・カード・背景の描画）は Claude Code のテスト機能で：

```bash
claude plugin test .
```
